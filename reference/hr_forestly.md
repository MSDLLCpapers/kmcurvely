# Display the HR forest plot, along with its KM plots

Display the HR forest plot, along with its KM plots

## Usage

``` r
hr_forestly(
  outdata,
  time_unit = c("days", "weeks", "months", "years"),
  y_label_kmplot = "Survival Probability",
  width = 1000,
  height_kmplot = 400,
  height_at_risk = 200,
  max_page = NULL
)
```

## Arguments

- outdata:

  outdata An `outdata` object created by
  [`format_hr_forestly()`](https://merck.github.io/kmcurvely/reference/format_hr_forestly.md).

- time_unit:

  A string specifying the unit of time in x-axis of the KM plot. must be
  one of "days", "weeks", "months", or "years". Default is "days".

- y_label_kmplot:

  A string specifying the y-axis label of the KM plot. Default is
  "Survival Probability".

- width:

  A numeric value of width of the entire plot in pixels. Default is
  1000.

- height_kmplot:

  A numeric value of height of the KM plot in pixels. Default is 400.

- height_at_risk:

  A numeric value of height of the at-risk table in pixels. Default is
  200.

- max_page:

  A numeric value of maximum number of subgroups to display per page.

## Value

An HR forest plot with subgroup KM plot saved as a `shiny.tag.list`
object.
