# Example Function for Time-to-Event Analysis

This function prepares the metadata required for conducting
time-to-event analysis using Kaplan-Meier curves in the context of a
clinical trial. It cleans and processes the datasets, defines the
analysis plan, and structures the metadata necessary for further
analysis.

## Usage

``` r
meta_tte_example_new()
```

## Value

A list containing metadata structured for time-to-event analysis.

## Examples

``` r
meta_data <- meta_tte_example_new()
# Use the returned meta_data in subsequent analysis functions.
```
